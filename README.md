# Lot Linker Fill

Chrome extension (MV3) for Lake Country Nissan / Hyundai Marketplace fill.

**Repo:** https://github.com/Jedv9/lot-linker-fill  
**Open in Cursor:** Clone or Open → this GitHub repo.

## Install
1. Download ZIP or clone
2. Chrome → `chrome://extensions` → Developer mode → Load unpacked → this folder (`manifest.json`)

## Refresh inventory
Click **Refresh inventory** in the popup. It pulls `packs.json` from this repo (raw main).

Weekly (Mondays ~9:15 CT): packs are rebuilt (Nissan + Hyundai) and pushed here.

## Filters
Store · Make · Model · Stock dropdowns + search bar.

## Version
See `manifest.json`.

Fill-only — you always hit Post. Never auto-posts.
