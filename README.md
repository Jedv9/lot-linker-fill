# Lot Linker Fill

Fill-only Chrome extension for Lake Country / Boucher WI Marketplace packs.

**You always click Post.** This never auto-posts.

## Install (unpacked)

1. Unzip `lot-linker-fill.zip`
2. Chrome → `chrome://extensions`
3. Turn **Developer mode** on (top right)
4. **Load unpacked** → select the unzipped `lot-linker-ext` folder (the one with `manifest.json`)
5. Pin the extension

## Use

1. Sign into the **dealership-authorized** Facebook Marketplace account
2. Create listing → **Vehicle for sale**
3. Click the extension → search stock # → **Fill Marketplace form**
4. Check fields → **you** click Post
5. If a field misses (Facebook redesigns often), use **Copy title / body / price**

## Import more packs

Paste Lot’s `ALL-EASY-PASTE.md` into Import, or load a `packs.json`.

Bundled with the Sep 4 Lake Country packs (92 units).


## Refresh inventory

Click **Refresh inventory** in the popup to pull the latest `packs.json` from the public GitHub repo (`Jedv9/lot-linker-fill`). Weekly inventory updates land there; teammates just click Refresh (no reinstall needed).

Feed URL: `https://raw.githubusercontent.com/Jedv9/lot-linker-fill/main/packs.json`
